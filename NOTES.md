# Ответы на вопросы к лабораторной работе

### 1. Почему на DELETE возвращается 204, а не 200?
HTTP-статус **204 No Content** указывает на то, что запрос успешно выполнен, но в ответе отсутствует тело (content). При удалении ресурса серверу обычно не требуется передавать клиенту какие-либо данные обратно, так как сущности больше не существует. Статус **200 OK** используется в случаях, когда сервер возвращает тело ответа (например, подтверждающее JSON-сообщение или удаленный объект). В архитектуре REST использование статуса 204 для успешного `DELETE` является общепринятым стандартом.

### 2. Что произойдёт с данными при перезапуске сервера и почему так работает массив в памяти?
При перезапуске сервера все текущие данные из массива `plants` будут безвозвратно утеряны, после чего при старте приложения функция `seed()` заново создаст 9 начальных записей. Данное поведение обусловлено тем, что массив объявлен в оперативной памяти (RAM) процесса Node.js. Оперативная память является энергозависимой и очищается при завершении или перезапуске процесса, в отличие от база данных или файлов на диске.

### 3. Зачем нужен вызов next(err) и что сломается, если его убрать?
Вызов `next(err)` с аргументом ошибки передает управление специализированному централизованному обработчику ошибок Express с сигнатурой `(err, req, res, next)`. Если убрать `next(err)` из блоков `try...catch` в контроллерах, сервер при возникновении ошибки "зависнет": клиентский HTTP-запрос будет вечно ждать ответа до истечения таймаута соединения, а сам клиент не получит содержательного ответа со статусом `500 Internal Server Error`.

### 4. Как именно в твоём коде реализовано персональное правило варианта? Приведи строки кода.
Персональное правило варианта 2 заключается в расчете даты следующего полива: `nextWatering = дата создания + wateringIntervalDays`.

В коде `src/services/plantService.js` это реализовано помощью функции `calculateNextWatering`:

```javascript
const calculateNextWatering = (createdAt, intervalDays) => {
  const date = new Date(createdAt);
  date.setDate(date.getDate() + Number(intervalDays));
  return date.toISOString().split('T')[0];
};
